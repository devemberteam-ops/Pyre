## CHECKPOINTS (memory_screen.dart · memory.dart · long_term_memory_screen.dart)
- **C1 (HIGH) — duplicate anchors from concurrent summarize.** Two separate `_summarising` latches: memory_screen.dart:32 (manual) and chat_screen.dart:258 (auto). Each only guards its own screen; the manual `_anyMemoryWorkInFlight` never consults the auto latch. Auto-summarize in flight + tap "Summarise now" → second concurrent generateCheckpoint → two checkpoints, same anchorMessageIdx + pathHash appended (memory.dart applyCheckpoint ~771 unconditional add). FIX: a SHARED per-chat in-flight guard at the SERVICE level (memory.dart) that generateCheckpoint acquires/releases; both callers handle "already running" (manual=toast, auto=skip).
- **C2 (HIGH) — pathHash computed AFTER the await against the live list.** generateCheckpoint builds body from [lastAnchor+1..cutoff] before a 10-30s await (memory.dart ~589/604), but computes `pathHash: computePathHash(chat.messages, cutoff)` at ~689 from the LIVE list. A variant swap / regen / removal during the await → stored pathHash describes a branch the summary doesn't match → recap silently dropped (filtered invalid) or bound to the wrong branch. FIX: snapshot pathHash at the SAME instant as cutoff/body (before the await).
- **C3 (HIGH) — edit/delete/wipe bypass the in-flight lock.** _editCheckpoint:143, _deleteCheckpoint:252, _wipeAll:289 do NOT check `_anyMemoryWorkInFlight` (only _runManualSummarise:52 + _retryCheckpoint:93 do). Retry in flight + delete/edit that checkpoint → replaceCheckpoint (memory.dart ~781) no-ops or overwrites the user's just-saved manual edit with the regeneration → silent data loss. FIX: gate the three destructive ops on the in-flight guard.
- **C4 (MEDIUM/UX) — "Summarise now" enabled-state only checks `_summarising`.** memory_screen.dart:496 gates onPressed on `_summarising` but the run-guard is `_anyMemoryWorkInFlight` (incl. `_retrying`). During a retry the button looks live, taps emit "another op running" toasts. FIX: gate onPressed + spinner + label on `_anyMemoryWorkInFlight`.
- **C5 (MEDIUM) — retry preserves a stale pathHash.** regenerateCheckpoint copies `pathHash: target.pathHash` after its await (memory.dart ~757); a branch change during the await → retried checkpoint carries a stale hash → filtered out → "retry succeeded then it's gone." FIX: snapshot/recompute pathHash for the range it actually summarized (same shape as C2).
- NOT bugs (cleared): per-checkpoint mtime/deleted (checkpoints ride the chat LWW blob via touchChat); auto-every off-by-one (correct).

## LIVE SHEET (live_sheet_screen.dart · live_sheet.dart)
- **L1 (HIGH, data loss) — "Generate from chat" destroys locked + manual facts.** _seedEntity (live_sheet_screen.dart:274-279) wholesale-replaces `entity.sections[s] = sections[s] ?? []` from parseSeedSheet (live_sheet.dart:367-390), which builds all-new unlocked facts and carries no prior state — NO lock check (unlike applyLiveSheetDelta which respects `f.locked` at live_sheet.dart:199-202). Per-entity wand → locked canon + hand edits gone. FIX: lock-preserving merge — keep all locked facts; merge/replace only unlocked.
- **L2 (related) — empty-sheet "Update state now" also wipes locked facts** (same root via _seedAllEntities). Covered by L1's fix.
- **L4 (HIGH-ish, silent corruption) — stale controller after snapshot swap.** Controllers cached by entityId/section/index for the screen's lifetime (live_sheet_screen.dart:72-76); NOT invalidated when the active snapshot changes (auto-update/append). clone() preserves entity ids (models.dart:2176) → key collides → putIfAbsent returns the OLD controller with OLD text (never refreshes) → display desync; blurring writes the stale value over the new fact → wrong-value persist + re-sync. FIX: invalidate controllers when the active snapshot id changes.
- **L3 (MEDIUM) — auto-update drops an in-flight (un-blurred) edit.** _FactRow commits only on blur; an auto-update tick rebuilds the list from a new snapshot → uncommitted text lost. FIX (lower priority): commit focused text before applying, or defer; flag if not safe tonight.
- NOT bugs (cleared): use-after-dispose (manifests as L4 stale-text, not a crash); wrong-chat application; default-ON seed idempotent.
